Enterprise FAQ

Answers to common deployment, security, and governance questions.

How does the Decomposed Trust Engine differ from standard SAST/DAST? +
Unlike traditional scanning tools that look for vulnerabilities post-build, our engine cryptographically validates the entire lineage of code, preventing unauthorized modifications from entering the build pipeline natively.
Is the Assurance Policy DSL compatible with Rego/OPA? +
Yes, our Assurance Policy DSL can compile down to Rego for seamless integration with existing Open Policy Agent deployments, while providing a more domain-specific syntax for software governance.
What does SLSA Level 4 compliance guarantee? +
SLSA Level 4 guarantees highest-level confidence that the software hasn't been tampered with. It requires two-person review of all changes and a hermetic, reproducible build process with non-falsifiable provenance.
Can EAORCS operate in completely airgapped environments? +
Yes, the Sovereign Airgap tier provides all components necessary for disconnected operations, including local certificate authorities and offline vulnerability database syncing capabilities.
How are automated external audit reports generated? +
The platform continuously maps real-time technical controls and attestations against compliance framework requirements (like ISO 27001), generating mathematically provable auditor-ready reports on demand.
Do you offer migration assistance from legacy compliance tools? +
Enterprise and Sovereign tiers include dedicated implementation engineers who will assist in translating existing compliance matrices into our deterministic policy DSL.
